Loot Ledger Minecraft Dungeons II hidden stats

    Where these numbers come from

    Two fan projects read the game's own data files. Most numbers match. Where they don't, the item shows a red 2 sources tag and both numbers, so you can test it in game.

    • MetaBot.gg, game build 1.1.1.0 (data built Oct 5, 2026). Weapons, armor, uniques, artifacts.
    • Dungeons II Stats Mod data file (Oct 2, 2026). Hit-by-hit damage, combo time, jump attack, reload.

    These are base numbers. In game, Item Power, enchantments and gear effects all change them. A Mobalytics write-up of the Reddit findings says damage scales with Item Power compared to the area's level, capped at 1.75×.

    Armor has no hidden defense number. Its weight label and its archetypes decide which effects it can roll. Uniques usually share their base item's stats, but not always; the item page lists every difference.

    Pulled Oct 22, 2026. A game patch can change any of this.
